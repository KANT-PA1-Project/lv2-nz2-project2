 해야 할 일
 로봇은 출발 구역에서 신호등이 12회 점멸하는 동안 색상 순서와 R·Y·G 횟수를 기억합니다. 바코드를 읽어 세 결과를
 정렬하고, L1·L2·L3에 각각 주사위 눈을 만듭니다. 마지막에는 카메라로 배치를 다시 확인하고 출발 구역으로 복귀합
 니다.

  항목                                        고정 조건

  경기장                                       4464×6364 mm / 기존 벽·기둥·박스 위치 유지

  퍽 수량                                      총 12개 / 빨강·초록 수량은 문제마다 랜덤 / 파랑 없음

  퍽 모양 구성                                   색상별 모양 수량 고정 없음 / 실제 12개 목록으로 출제
                                            검증

  규격·높이                                     Ø30×60 또는 30×30×60 / 퍽 바닥 70, 윗면 130 mm

  장소·신호                                     L1~L3 세 곳 / 신호등 1개 / 점멸 총 12회

  시작 배치                                     맵의 시작 박스 6곳 × 퍽 2개 / 목적지 L1~L3는 비움

  동시 완료                                     퍽 12개를 세 장소에 동시에 놓음 / 중복 사용 불가

  시간·회차                                     시간 제한 없음 / 공식 2회 중 높은 회차 전체 점수


 공통 속성의 의미
 R은 빨간 퍽만, G는 초록 퍽만 사용합니다. R·G에서는 모양이 달라도 됩니다. Y는 색상이 달라도 되지만 원기둥 또는
 직육면체 중 한 모양으로 모두 통일합니다. 노란 퍽은 사용하지 않습니다. 각 그룹의 퍽 개수는 해당 신호의 횟수입니
 다.

 L1=(3670,950), L2=(2202,3700), L3=(3670,5354). 중앙 820×820 받침대의 북쪽을 L2로 사용하고 중앙에는 시작 퍽을
 놓지 않습니다. 중앙은 410×410×70 박스 4개, L1·L3는 기존 205×205×70 박스를 사용합니다. 기존 작은 박스 6개를
 시작 박스로 전환하여 각 2개씩 퍽을 분산합니다. 박스는 총 12개입니다.

 02 | 신호와 바코드 규칙
 아래 점멸 시간과 동률 규칙은 모든 팀에 동일하게 적용하는 운영 기준입니다.

  항목                                 처리 규칙

  설치                                 바닥에 세로로 세움 / 하단 기준 (80,950,0) mm / +X 방
                                     향

  관측                                 로봇 중심 (734,950) mm에서 -X 방향 관측 후 출발

  시작                                 로봇 준비 완료 후 운영자가 신호 시퀀스 시작

  1회 점멸                              한 색 1초 켜짐 + 1초 소등. 연속 같은 색도 소등으로 구
                                     별

  종료                                 12번째 점멸 후 3초 연속 소등. 별도의 초록 출발 신호
                                     없음

  출발                                 12개 기록 완료·종료 확인·바코드 해독 후 이동

  R/Y/G                              R=빨강 / Y=노랑·모양 통일 / G=초록

  허용 횟수                              각 1~6회, 합계 12. 실제 퍽 구성으로 풀이 가능한 조합
                                     만 출제

                                     금지

  동률                                 횟수가 같으면 R → Y → G 순서 유지


  Code 128 문자열                       L1 → L2 → L3 순서

  P2-01 / P2-03                      오름차순: 적은 횟수부터

  P2-02 / P2-04                      내림차순: 많은 횟수부터

 기존 바코드 4종은 그대로 쓰고 두 개씩 같은 의미로 대응합니다. 정렬 대상은 R·Y·G 그룹의 횟수이며, 퍽 ID나 장소
 번호를 정렬하는 것이 아닙니다. 기록 로그에는 색상 순서 12개와 각 횟수를 모두 저장합니다.

 03 | 주사위 눈과 위치 판정
 지도 위쪽이 +Y입니다. 모든 장소에서 같은 방향으로 배치합니다.




  항목                               기준

  3×3 격자                           장소 중심 기준 X,Y 각각 -60, 0, +60 mm

  배치 영역                            180×180 mm / 작은 박스 205×205 위에도 설치 가능

  성공                               정해진 점마다 퍽 1개, 중심 오차 10 mm 이내, 2초 안정

  높이                               모든 퍽 바닥 Z=70 mm. 쌓기·바닥 임시 보관 금지

  방향                               2·3의 대각선, 6의 좌우 두 열은 그림대로. 회전 대체 불
                                   가

 빈 격자에 추가 퍽이 있으면 해당 장소의 눈 배치는 실패입니다. 한 퍽은 한 장소에만 사용합니다. 집기 순서는 자유
 이며, R/G부터 가져가서 Y가 불가능해지지 않도록 전체 할당을 먼저 계획해야 합니다.

 04 | 랜덤 퍽과 출제 검증
 총 12개만 고정합니다. 빨강·초록 수량은 랜덤이며, 풀이 가능한 문제만 제시합니다.

  구분                                         조건

  총수량                                        빨강 퍽 수 + 초록 퍽 수 = 12개

  색상·모양                                      색상별 수량과 모양별 수량을 일률적으로 고정하지 않음

  신호                                         R/Y/G 각각 1~6회, 총 12회

  R 그룹                                       R 점멸 횟수만큼 빨간 퍽 사용

  G 그룹                                       G 점멸 횟수만큼 초록 퍽 사용

  Y 그룹                                       Y 점멸 횟수만큼 한 모양으로 통일 / 색상 혼합 가능

  공통 조건                                      전체 12개를 중복·누락 없이 한 번씩 사용


 운영자 검증 순서
 ① 실제 퍽 12개의 ID·색상·모양을 등록합니다. ② 횟수 합계 12인 신호 후보를 선택합니다. ③ Y 퍽을 한 모양으로 고
 르고, 남은 퍽이 R/G 조건에 정확히 맞는지 검사합니다. ④ 유효한 전체 할당이 하나 이상인 후보만 추첨합니다. 후보
 가 없으면 퍽 구성 또는 신호 후보를 다시 생성합니다.

 풀이 가능한 예
 빨강 8개·초록 4개이고 빨강에 같은 모양 3개가 있다면 R5·Y3·G4가 가능합니다. 같은 모양의 빨간 퍽 3개를 Y에 쓰고
 나머지 빨강 5개와 초록 4개를 각각 R/G에 씁니다. 실제 목록의 모양 조건까지 확인해야 합니다.

 ID와 공개 예제
 ID 0~11은 퍽 식별자이며 색상을 영구 지정하지 않습니다. 문제마다 실제 색상·모양과 해당 회차 등록표를 확인합니
 다. Q1 그림과 placement.csv/mission.json은 빨강 6·초록 6인 설명용 예제입니다. 이 비율은 경기 고정 조건이 아닙니
 다. example-combinations.csv도 이 예제 구성에만 적용됩니다.

 팀별 제출 문제
 팀마다 실제 퍽 12개의 속성·시작 좌표, 12회 신호 순서, 바코드, 유효 할당 정답과 검증 결과를 제출합니다. 맵 추첨은
 완료되었고 선정된 주사위 맵을 사용하며, 같은 회차에는 전 팀이 같은 퍽 구성·배치·신호를 사용합니다.

 05 | 공개 연습 문제 Q1
 실전에서는 운영자가 선택한 다른 시퀀스가 제시될 수 있습니다.

 제시 신호
 RGRRGRGGYGYG

  문제 조건                              내용

  바코드                                P2-01 (오름차순)

  기억할 것                              12개 색상의 순서와 R·Y·G 각각의 횟수

  작업                                 세 장소에 주사위 눈을 만들고 재인식 후 복귀

  기록                                 signal.json, allocation.json, 이동 전후 이미지·영상


 수행 순서
 ① 출발 구역에서 바코드 읽기 → ② 12회 점멸 관측 → ③ 횟수 계산·유효성 확인 → ④ 세 장소에 그룹 배정 → ⑤ 분
 산된 시작 박스의 퍽을 탐색·인식하고 전체 할당 → ⑥ 분산 박스 탐색·주행·집기·놓기 → ⑦ 세 장소 재검증 → ⑧ 복
 귀.

 오류와 종료
 12회 미만/초과, 불명 색상, 미등록 바코드, ID 중복·누락이면 오류를 기록하고 안전하게 정지합니다. 팀 오류로 신호
 를 다시 보여주거나 수동 수정 후 같은 회차를 이어가지 않습니다. 운영 장비 오류는 무효 처리 후 같은 조건으로 재
 시도합니다. 비상정지·포기·고장 시 그때까지의 유효 점수를 기록합니다.

 06 | 채점표
 경기 원점수 100점. 프로젝트 종합 평가는 별도 팀 80점 + 개인 20점입니다.

  항목                             배점                판정 기준

  신호 순서 기억                       12                12개 시점별 색상 일치 각 1점

  색상별 횟수                         9                 R·Y·G 정답 횟수 각 3점

  바코드 해석                         4                 실물 코드와 정렬 방향 모두 일치

  장소 그룹 배정                       9                 정답 그룹을 L1~L3에 배정 각 3점

  색상·모양 선택                       18                각 장소 개수와 R/G 색상 또는 Y 모
                                                   양 모두 충족 각 6점

  주사위 눈 배치                       30                각 장소 정답 눈·위치·안정 조건 모두
                                                    충족 각 10점

  이동 후 검증                        8                 새 관측 기반 장소별 ID·위치 기록 6
                                                   점 + 전체 중복/누락 판정 2점

  복귀                             10                차체 전체가 출발 구역 안에서 3초
                                                   정지

  합계                             100               12+9+4+9+18+30+8+10

 목표 상태를 그대로 복사한 로그는 재검증으로 인정하지 않습니다. 장소별 관측 기록은 각 2점입니다. 순서/횟수/바
 코드는 실제 센서 관측 기록으로 평가합니다. 임의 감점과 시간 가산점은 없습니다. 실기 과제별 공식 2회 중 높은 회
 차 전체 점수를 쓰며 회차 간 성공 항목을 합치지 않습니다.

 프로젝트의 통합 경기 항목 25점은 원점수×0.20 + 자율 완주 5점입니다. 자율 완주는 신호·정렬·세 장소 정답·재검증·
 복귀 전부 성공했을 때만 인정합니다. 팀 문제 검토 10·기본 20·결합 15·통합 25·재현/문서 10·개인 20의 기존 구조를
 유지합니다.

 시작 박스 1~6 중심: (1468,950), (3670,3152), (2936,5354), (734,5354), (2202,5354), (3670,3886) mm. 각

 퍽은 맵에 분산되며 L1~L3는 빈 상태로 시작합니다. L2 격자 중심=(2202,3700). 장소 태그는 접근 방향 수직 면에 부
 착하고 중심 높이 35 mm로 합니다. 신호등은 바닥 기준 (80,950,0) mm에 본체 하단이 닿도록 세로로 세우며 +X를
 향합니다. 전체 높이와 발광면 높이는 실물 신호등 기준으로 합니다. 바코드 중심은 (80,650,450) mm, +X 방향입니다.
 왼쪽 아래 기둥 중심이 X/Y 원점, 바닥이 Z=0입니다. 신호등 받침을 바닥에 안정적으로 놓고 출발 중심 (734,950)에
 서 -X를 보며 관측합니다. 카메라 시야·각도는 실물 사전 확인합니다.
