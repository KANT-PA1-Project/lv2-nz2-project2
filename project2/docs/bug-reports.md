## #1 목표 앞에서 조향만 반복하며 정체

- 라벨: `bug`, `nav2`
- 시험 ID: T-NAV-02 → T-NAV-05
- 환경: 모의 (Gazebo, Nav2 1.5.0 MPPI Omni, r12 스월브)
- 구현자: 정수용 / 검토자: 천경호

### 발생 조건
- facing 경로 L3_S (yaw 90°). 로봇이 목표 452 mm 앞에서 150 s 넘게 멈춤.
- 영상에서 150~280 s 동안 바퀴 조향만 반복함.

### 기대 결과 / 실제 결과
- 기대: 5/5 도착
- 실제: 2/5. L3_S 는 시간 초과, B5371_S·START 는 AMCL 위치가 틀어져 경로 계획 실패.

### 원인
1. r12 `HOLD_SPEED = 1e-4 m/s` 때문에 아주 작은 잡음 명령에도 조향을 다시 돌림.
2. 측정 조향각을 보지 않아서, 바퀴가 정렬되기 전에 굴러 미끄러짐 → odom 이 틀어짐.
3. `optimize_angle` 히스테리시스 0.17 rad + 조향 한계 ±90°. 게걸음 방향이 경계라 방향이 10° 만 흔들려도 바퀴가 180° 뒤집힘.

### 수정 내용 (팀 r12 코드는 수정하지 않음)
- `cmd_frame_adapter.py` v2
  - 데드밴드: 병진 < 0.01 m/s 이고 |wz| < 0.02 rad/s 이면 0
  - 정렬 게이트: 모듈 목표각과 측정 조향 오차 > 0.35 rad 이면 속도를 0.003 m/s 로 줄이고, 그 아래에서는 cos(오차) 배
- `r12_sim_overrides.yaml`: 조향 한계 1.92 rad (±110°). 실물은 케이블·펌웨어 한계 확인 전까지 ±90° 유지.

### 재시험 결과
- 수정 전: facing 2/5 (T-NAV-02)
- 수정 후: facing 5/5, 정지 오차 최대 65 mm (T-NAV-05)
- 남은 문제: 목표 앞 마지막 정렬에서 조향만 도는 시간이 있음 (안전 문제 아님).

## #2 제자리 회전을 진전으로 안 봐서 주행 중단

- 라벨: `bug`, `nav2`
- 시험 ID: T-NAV-03 → T-NAV-05
- 환경: 모의 (Gazebo)
- 구현자: 정수용 / 검토자: 천경호

### 발생 조건
L1_S 에서 위치는 38 mm 까지 도착했지만, yaw −21.6° 가 남은 채 중단됨.

### 기대 결과 / 실제 결과
- 기대: yaw 0.05 rad 이내로 정렬
- 실제: "Failed to make progress" → 복구 → "Resulting plan has 0 poses" (오류 103) → 중단. facing 3/5.

### 원인
1. 마지막 회전 단계에서 명령 wz 0.11 rad/s 에 0.01~0.02 m/s 잡음 병진이 섞임.
2. 이 잡음은 회전 때 바퀴 속도(0.11 × 0.175 = 0.019 m/s)와 비슷한 크기라서 모듈 목표각이 계속 바뀜. 그래서 실제로는 거의 돌지 못함.
3. SimpleProgressChecker 는 제자리 회전을 진전으로 보지 않아서 10 s 뒤 실패 처리함.

### 수정 내용 (v9)
- progress_checker → PoseProgressChecker (0.05 m 또는 0.2 rad, 15 s)
- TwirlingCritic 가중치 10 → 25, GoalAngleCritic 3 → 8
- `cmd_frame_adapter`: 회전 중(|wz| ≥ 0.02)에 병진 < 0.02 m/s 이면 병진을 0으로 = 순수 회전

### 재시험 결과
facing 3/5 (T-NAV-03) → 4/5 (T-NAV-04, 남은 실패는 #3) → 5/5 (T-NAV-05)
