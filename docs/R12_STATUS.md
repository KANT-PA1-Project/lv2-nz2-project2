## 원격 중단

pa24·pa33·pa28 담당자가 R12 Isaac/learner/감독기/순차 실행기/실험 잠금 없음 확인. 공유 Omniverse Hub는 유지했다. 예약 작업은 로컬 전용 지시로 변경했다. 중단 기록은 `r12/evidence/*stop.json`에 있다.

## 중요 정정

- v130의 424.079ms는 subscriber 검증 완료 endpoint였다. 최종 producer ACK 시간으로 보고하지 않는다. ACK는 v133부터 직접 계측했다.
- v41/v43 인식은 19/20. v44의 20/20은 추가 render를 수행한 별도 벤치 결과다.
- pa28 v147 replay의 world→base z=8mm 누락을 정정했다. 이전 수치 증거는 그대로 승격하지 않는다.
- 종료 코드 0, 학습 종료, CPU 시험 통과, 정적 기하 통과는 전체 미션 성공과 다르다.

## 미션 규칙 반영

원본 미션/마커 등록표에서 tag36h11, 퍽 ID0~11(검은 영역16mm/흰 영역20mm), 목적지 ID12/13/14(48mm/60mm)를 확인했다. 사용자의 최신 지시에 따라 목적지 마커는 윗면 기준으로 다룬다. 세 태그의 정확한 장착 변환과 하나의 상자에 대한 배치 기준은 미확정이므로 임의 좌표를 만들지 않는다. 주사위 눈 배치는 맵 축 기준 60mm 간격, 위치 허용오차10mm, 안정2초 조건을 반영했다. 과거 문서의 색상/상자 높이를 자동으로 새 기준에 덮어쓰지 않는다.

## 배포 범위

`r12/`는 기존 개발 저장소의 소스/설정/테스트/정책/CAD 스냅샷이다. `r12/experiments/`에는 최신 원격 검증 소스와 미검증 후보를 구분 보존한다. v45는 **미실행 후보**다. 로컬 절대 경로와 별도 Isaac/ROS 의존성이 있으므로 clone 즉시 전체 미션 실행 가능한 완성 배포판으로 간주하면 안 된다.
