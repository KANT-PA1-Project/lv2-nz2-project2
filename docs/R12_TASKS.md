1. 런타임 연결 전 경로·모델·스키마·자원 사전 검사와 소유 프로세스/잠금 확인.
2. 단위 카메라 ready/IPC/ROS 정상 종료를 통합 구성에서 검증.
3. 최종 미로 센서 기반 이동과 손목 관측을 연결하면서 팔 파지/놓기 단위 물리시험 병행.
4. 목적지 세 태그의 장착 변환을 확인하고 주사위 눈 배치 목표를 관측 좌표계로 변환.
