# 흰색 퍽 스토리지에 태그 붙이기

1. A4 도안 slot_labels_A4.pdf를 흰색 무광 접착 라벨지에 **실제 크기 100%**로 출력합니다. 아래 기준선의 길이가 50 mm인지 확인한 뒤 회색 재단선을 따라 자릅니다. 단단한 인서트를 출력할 필요가 없습니다.
2. ID 3과 7은 31 mm 바닥에 맞는 30 mm 라벨입니다. 나머지는 35 mm 바닥에 맞는 34 mm 라벨입니다. 같은 ID를 두 곳에 붙이지 마세요. 각 라벨의 검은 테두리 한 변은 21.6 mm입니다. 흰 여백을 살리고 주름 없이 붙입니다. 얇은 라벨 실물 두께가 0.12 mm와 크게 다르면 slots.json의 높이를 조정합니다.
3. 태그가 보이고 바닥 네 귀퉁이를 구분할 수 있는 빈 슬롯을 촬영합니다. 실제 손목 RGB의 CameraInfo와 영상 시각의 base_link ← optical TF가 필요합니다. 실측 바닥 높이가 CAD의 50 mm와 다르면 slots.json의 Z를 먼저 수정합니다. 카메라 외부 보정과 관절 영점 오차는 태그 부착 오프셋과 별도로 남습니다.
4. GUI에서 **바닥 안쪽 네 귀퉁이**를 둘레 순서대로 클릭합니다. 첫 귀퉁이는 어디든 됩니다. 입구 윗면은 바닥보다 25 mm 높아서 사용하면 안 됩니다. 실제 꼭짓점 위치가 모호한 슬롯은 같은 트레이에서 더 잘 보이는 슬롯을 먼저 보정합니다.
5. 작업 직전 빈 상태에서 중심을 읽고, 퍽에 가려지면 마지막 관측 시각을 확인합니다. 슬롯 중심 Z는 바닥 높이입니다. 퍽을 놓는 그리퍼 높이에는 퍽 두께, 파지점, 여유량을 별도로 적용합니다.

## 위치표

차체 +X를 앞, +Y를 왼쪽으로 봅니다. 단위는 mm입니다.

| Y | X = −35 | X = +35 |
|---|---|---|
| +145 | ID 0 | ID 1 |
| +95 | ID 2 | ID 3 |
| −95 | ID 4 | ID 5 |
| −145 | ID 6 | ID 7 |

## 보정과 실시간 출력

ROS 2, cv_bridge, tf2_ros, scipy, numpy, cv2.aruco를 사용할 수 있어야 합니다. 클릭 입력에는 GUI를 지원하는 OpenCV가 필요합니다. 아래 명령은 이 폴더에서 실행합니다. 실물 카메라 토픽이 다르면 --image와 --info로 지정합니다.

~~~bash
python capture_ros.py capture/id2
python locate.py capture/id2.png capture/id2.json --offsets measured.json --calibrate 2
python capture_ros.py capture/id6
python locate.py capture/id6.png capture/id6.json --offsets measured.json --calibrate 6
python capture_ros.py --track measured.json
ros2 topic echo /puck_slots/centers
~~~

보정할 ID별로 두 번째 명령을 반복합니다. 창이 없는 환경에서는 --corners 뒤에 u1 v1 u2 v2 u3 v3 u4 v4를 입력합니다. 시뮬레이션의 ROS 시계를 사용할 때는 capture_ros.py에 --sim-time을 추가합니다.

각 출력에 차체 기준 중심(m), 관측 시각, 근거가 된 태그 ID를 담습니다. direct는 해당 태그의 실측 오프셋을 적용한 결과입니다. rigid_tray는 같은 트레이의 보정된 태그와 CAD 슬롯 간격으로 추정한 결과입니다. cached는 새 기준 태그가 보이지 않아 유지한 이전 좌표입니다. 트레이를 재장착하거나 태그를 다시 붙이면 재보정하고, cached만 남은 상태에서 트레이가 움직였다면 다시 관측합니다. 기준 태그 하나로 다른 칸을 추정할 때는 트레이의 휨과 출력 수축이 오차로 남습니다.

## 확인한 범위

- 인쇄용 PDF를 래스터화해 ID 0~7을 모두 디코딩했습니다.
- MuJoCo 상부 검사 카메라에서 라벨을 XY로 약 1.42 mm, 각도 약 1.43° 어긋나게 배치했습니다. 한 영상에서 시뮬레이션 바닥 꼭짓점을 픽셀 단위로 반올림해 보정하고, 다른 영상으로 평가한 직접 관측 최대 오차는 0.09 mm였습니다.
- 손목 D435 시점에서 ID 2와 6을 각각 기준으로 삼아 양쪽 트레이의 8개 중심을 계산했습니다. CAD 중심 대비 최대 오차는 0.32 mm 이내였습니다. views.json은 인식 시험에 사용한 관절 자세이며 충돌 검증된 실물 이동 경로가 아닙니다.
- 흰 트레이 재질은 CAD와 시뮬레이터의 외관에만 적용했습니다. 이미 출력된 부품에는 종이 라벨만 부착합니다. 전체 조립 STL은 색 정보를 담지 않으므로 라벨은 PDF를 사용합니다.
- 실물 카메라·조명, 접착 두께, 사용자 클릭 오차, ROS 2 실시간 발행과 실제 퍽 투입은 미검증입니다.
